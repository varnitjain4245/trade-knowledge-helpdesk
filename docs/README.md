# Trade Knowledge Helpdesk

A helpdesk for India's commerce and industry administration that answers only from
records it can name, and says so when it cannot.

This page runs entirely in the browser. The records, the search and the matching all
live here — nothing you type is sent anywhere, and there is no API key to leak.

## What it does

- **Every answer quotes its record**, with the issuing authority and the date it was
  issued, so the answer can be checked rather than trusted.
- **Where two records disagree**, both are shown and neither is chosen for you. A
  helpdesk that silently picks one is presenting a guess as the position.
- **Where nothing covers the question**, it says so. It does not guess.
- **Speak to it.** Hands-free conversation using the browser's own speech engines.
- **Six languages**, with per-script typography — Devanagari and Tamil need more
  vertical room than Latin, and a layout tuned only on English breaks in Hindi.

## Honest limits

The records, rates and scheme figures are illustrative — the procedures and terminology
follow how the administration actually works, but the specific numbers are for the
demonstration. Check the published notification before acting on a figure.

Matching is lexical rather than semantic, so a question phrased far from the records'
wording may be refused even when the answer is present. Speech recognition uses the
browser's engine, which is weaker on Indian languages than a server-side model.

Built for the Smart India Hackathon. Not an official service.
